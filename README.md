# MTPoxy Panel

Python-панель, которая создаёт Telegram **WEB-proxy** вместе с бесплатным
поддоменом dynv6, HTTPS и полноценным сайтом рецептов. Управление из браузера
на Android, Windows и других устройствах. В Python-части используются только
модули стандартной библиотеки.

## Установка одной командой

Выполните от root на VPS:

```bash
curl -fsSL https://raw.githubusercontent.com/riehnh/mtpoxy-panel/main/install.sh | bash -s -- --repo https://github.com/riehnh/mtpoxy-panel
```

Установщик выводит URL `https://IP:9443/manage`, пароль и SHA-256 отпечаток
сертификата. Первая установка включает сборку серверных компонентов и может
занять несколько минут. При нестандартной сети добавьте `--public-ip IPV4`.

Поддерживаются Ubuntu 22.04+ и Debian 12+, архитектура amd64/x86_64,
systemd и публичный IPv4. Откройте TCP 80, 443 и 9443 в firewall хостинга.
При активном UFW установщик добавляет эти разрешения.

Первичный вход по IP использует самоподписанный HTTPS-сертификат. Браузер
предупредит о нём. Сверьте отпечаток с выводом установщика и подтвердите
переход. После создания первого сайта панель доступна и по
`https://ИМЯ.dynv6.net/manage` с публичным сертификатом.

## Настройка в браузере

1. Зарегистрируйтесь на https://dynv6.com и получите HTTP token в разделе Keys.
2. Откройте панель и войдите с паролем из терминала.
3. Сохраните токен dynv6 и email для ACME/HTTPS.
4. Нажмите **Создать WEB-proxy**. Имя `recipebook-xxxxxx.dynv6.net`
   генерируется автоматически. Также можно указать своё кулинарное имя.
5. Дождитесь DNS, запуска служб и HTTPS. Откройте готовую ссылку в Telegram.

Кнопку можно нажимать повторно: создаются новый кулинарный поддомен,
отдельный secret и новое подключение на том же VPS. Программной квоты на
число записей нет. Свободные порты выбираются автоматически, фактическое
количество ограничивают ресурсы VPS, DNS API и правила выпуска сертификатов.
Установки выполняются последовательно. Для неудачной установки кнопка
«Повторить» использует ранее созданное имя.

Нужен Telegram с поддержкой типа WEB. Ссылка `t.me/webproxy` содержит
`server` и `secret`. Эквивалент `tg://webproxy` используется кнопкой панели.

## Что создаётся

- Бесплатная DNS-зона через REST API dynv6. При повторе используется ранее
  созданная зона.
- Отдельный Telegram backend и WEB relay для каждого сайта, отдельные secret
  и ключ подписи. Процессы управляются systemd и запускаются после перезагрузки.
- Перед статусом «Готово» проверяется настоящий MTProto-ответ Telegram
  `resPQ`, а также HTTPS-сертификат и сайт.
- Сайт Recipe Book с фотографиями, поиском по названию и ингредиентам,
  фильтром кухни, быстрыми блюдами и полными рецептами в диалоге.
- Каталог из открытого API DummyJSON Recipes. Данные и инструкции на
  английском, интерфейс на русском. Обновление раз в сутки с сохранением
  последнего успешного каталога.
- Caddy получает и обновляет HTTPS-сертификаты.
- HAProxy маршрутизирует новый SNI в WEB-proxy. Другие подключения на 443
  передаются существующему TCP-сервису на `127.0.0.1:443`.

Если исходящие соединения к Telegram блокируются, раскройте в настройках
**Исходящий SOCKS5** и укажите адрес, порт и при необходимости логин/пароль.
В этом режиме используется Python-backend alexbers/mtprotoproxy, работающий
через SOCKS5 с серверами Telegram. На VPS с существующим локальным SOCKS5 в
x-ui установщик переносит его параметры в настройки панели автоматически.
Пароль SOCKS5 не возвращается браузеру. В прямом режиме используется
официальный Telegram MTProxy. Python-backend устанавливается из закреплённого
коммита, библиотеки cryptography и PySocks — пакетами Ubuntu/Debian.
Проверка обращается к пяти дата-центрам Telegram с повтором при тайм-ауте.
Если отвечает только часть, панель выводит предупреждение. Это может влиять
на подключение аккаунтов и медиа, требуется проверить или сменить выход VPS.

Установка не предполагает работающего веб-сервера на 80. Если VPS уже
обслуживает сайты через nginx/Caddy, освободите 80 или интегрируйте
конфигурацию вручную. Существующий сервис на 443 должен принимать IPv4
соединения через loopback. Конфигурации x-ui/Xray и его прокси не изменяются.
Прямая маршрутизация с NAT провайдера и IPv6 требуют отдельной интеграции.

## Приватность и доступ

API-токен хранится в `/var/lib/mtpoxy/settings.json` с правами 0600 и не
возвращается браузеру. Пароль хранится как PBKDF2-SHA256 с индивидуальной
солью. Есть защита POST-запросов по Origin и CSRF, ограничение попыток входа,
HttpOnly/SameSite cookies и срок сессии 8 часов. Панель управляет systemd и
firewall, поэтому служба работает от root. Доступ к ней даёт управление
создаваемыми прокси. Файлы конфигурации и пароль не входят в репозиторий.

Пароль первого входа можно повторно посмотреть от root:

```bash
cat /var/lib/mtpoxy/initial-password
```

Для смены пароля от root:

```bash
python3 /opt/mtpoxy/reset_password.py
```

Проверить состояние:

```bash
systemctl status mtpoxy-panel mtpoxy-caddy mtpoxy-router
journalctl -u mtpoxy-panel -n 100 --no-pager
```

Состояние задач сохраняется. После перезапуска прерванная установка получает
статус ошибки, её можно повторить кнопкой в панели. Если dynv6 не публикует
DNS, задача сохраняет имя и предлагает повтор без повторной регистрации.

Отключить перенаправление порта 443 и вернуть входящий трафик напрямую
предыдущему сервису:

```bash
systemctl disable --now mtpoxy-routing.service mtpoxy-router.service
```

Для резервной копии сохраните `/var/lib/mtpoxy`, `/etc/mtpoxy`,
`/etc/mtproxy` и папку сертификатов `/var/lib/mtpoxy/caddy`.

## Исходники

Репозиторий проекта — https://github.com/riehnh/mtpoxy-panel.
Чтобы скачать исходники:

```bash
git clone https://github.com/riehnh/mtpoxy-panel.git
cd mtpoxy-panel
```

Установка из скачанной папки на VPS:

```bash
sudo bash install.sh --source "$PWD"
```

## Проверки

```bash
python3 -m unittest discover -s tests -v
bash -n install.sh
```

Приложение включает исходники панели, сайта и установщика. Telegram WEB relay
собирается из закреплённого коммита официального проекта
https://github.com/telegramdesktop/tproxy-server, MTProxy — его установщиком.
Caddy — https://caddyserver.com, HAProxy — пакет Ubuntu/Debian.
Python-backend — https://github.com/alexbers/mtprotoproxy.
Лицензии сторонних компонентов сохраняются в их поставках. API каталога:
https://dummyjson.com/docs/recipes.
